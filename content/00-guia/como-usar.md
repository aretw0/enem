# Como usar este repositório

## Fluxo recomendado

1. **Compreender a prova**: leia os fundamentos do ENEM.
2. **Definir meta**: curso alvo + nota alvo + prazo.
3. **Escolher trilha**: selecione a trilha mais alinhada ao seu objetivo.
4. **Executar ciclo semanal**:
   - estudo de base;
   - treino por questões;
   - revisão ativa;
   - simulado e ajuste.
5. **Registrar aprendizados**: toda semana, anotar erros recorrentes e ações.

## Regra de ouro

Use o repositório como um jardim: adicionar pouco, podar sempre, revisar com frequência.
